# rust-dns 0.1.6 发布说明

修复 LuCI 页面在关闭标签页时偶尔卡顿的问题：Cloudflare 优选结果不再一次渲染
全部行，后台标签页也不再继续轮询。DNS 核心与 0.1.5 相同，本版本只改了 LuCI
前端。

## 一、根因

### 1. 优选结果一次渲染上千行

一次优选可能产生 1000 行结果，旧页面会为每一行创建 DOM 节点，并挂上复选框、
保存按钮和事件监听器。关闭标签页时浏览器需要销毁这棵很大的 DOM 树和全部
监听器，浏览器越忙、机器越慢，停顿就越明显。

### 2. 标签页隐藏后仍在轮询

LuCI 的 `poll.add()` 用 `setInterval()` 定时执行，不区分标签页是否可见：

| 页面 | 间隔 | 隐藏后仍在做的事 |
|---|---|---|
| Cloudflare 优选 | 1 秒 | 查询优选状态、更新页面 |
| Statistics | 5 秒 | 查询统计/历史/Top/日志并重建图表和表格 |
| Basic | 5 秒 | 查询服务状态并重绘状态区 |
| Logs | 5 秒 | 读取日志尾部并重新过滤、渲染 |
| System Upgrade | 1.5 秒 | 查询升级状态 |

最小化或切到别的标签页后，这些工作仍在继续，窗口关闭/恢复时更容易堆积。

## 二、0.1.6 的修复

| # | 修复 |
|---|---|
| 1 | Cloudflare 结果表**分页**，每页 100 行，提供 Previous / Next 和 `Showing x-y of z` |
| 2 | 全选只作用于当前页，不会误选没显示的行 |
| 3 | 过滤、排序、载入结果或清空结果时回到第一页 |
| 4 | 所有页面轮询在 `document.visibilityState === 'hidden'` 时跳过，回到前台立即刷新一次 |
| 5 | 优选状态、统计、日志、服务状态、升级状态的定时器不再为后台标签页做 RPC 和 DOM 工作 |

分页后，页面里最多只有 100 行结果，关闭标签页需要销毁的节点从数千个降到
百来个；后台暂停轮询则避免窗口隐藏期间的持续开销。

## 三、升级到 0.1.6

只有 LuCI 前端变化。已经装好 0.1.5 的，安装新的 `luci-app-rust-dns` 包即可：

```sh
cd /tmp
BASE=https://github.com/moliango/rust-dns/releases/download/v0.1.6
wget "$BASE/24.10.8_x86_64-24.10.8_luci-app-rust-dns_0.1.6-r1_all.ipk"
opkg install ./24.10.8_x86_64-24.10.8_luci-app-rust-dns_0.1.6-r1_all.ipk
```

25.12 / apk 换成对应的 `luci-app-rust-dns-0.1.6-r1.apk`：

```sh
apk add --allow-untrusted ./25.12.6_x86_64-25.12.6_luci-app-rust-dns-0.1.6-r1.apk
```

也可以继续用 **System Upgrade** 页面整体升级，它会选择匹配当前 OpenWrt 分支
和架构的全部包。文件名里的版本/架构按你的路由器替换，完整清单见
[`INSTALL-openwrt.md`](INSTALL-openwrt.md)。

安装后如果页面还是旧样式，清一下缓存并重新登录：

```sh
rm -rf /tmp/luci-*
```

## 四、验证

1. 打开 Cloudflare 优选，载入一次 1000 候选的结果，确认表格下方出现
   `Page 1 of N`，翻页正常，“全选”只勾选当前页。
2. 打开 Statistics 或 Basic，切到别的标签页几十秒再回来，数据会立即刷新一次。
3. 在优选结果页直接关闭标签页，卡顿应明显减轻。

若仍明显卡顿，请记录卡顿发生在哪个页面、结果有多少行，以及路由器型号，便于
继续定位。
